How to use Fireporter

A step-by-step walkthrough of every feature in the Figma plugin and the Roblox Studio plugin, organized from the basics to advanced and beta tools.

Getting started

The core workflow, without any extra toggles.

01

Install both plugins

Add the Figma plugin from the Figma Community and the companion plugin to Roblox Studio from the Creator Store.

02

Select something in Figma

Select one frame, group, or layer (or several at once) — whatever you want to bring into Roblox.

03

Open Fireporter and click Export

The Export tab turns your selection into Roblox-ready data and shows it in the code box. In Normal mode images are not uploaded; to have them uploaded for you, use Upload mode (see Beta features).

04

Copy the code

Click Copy to put the exported data on your clipboard.

05

Import it in Studio

In Roblox Studio, select a ScreenGui in the Explorer, open the Fireporter widget, paste the code into the text box, and click Import.

Basics

On by default

These live in the top row of the Export tab. They're switched on by default and cover what most exports need.

Include Strokes

Basics

Carries Figma borders/outlines over as a Roblox UIStroke, matching color, thickness, and inside/center/outside alignment.

Include Effects

Basics

Accounts for shadows and blurs when measuring a layer, so exported sizes and positions match what you see in Figma instead of just the raw layout box.

Auto Scale

Basics

Converts pixel sizes and positions into scale values, so your UI adapts across different screen resolutions in Roblox instead of staying a fixed pixel size.

Include Gradients

Basics

Exports linear gradient fills as a Roblox UIGradient, keeping stop colors, positions, and rotation.

Include Text

Basics

Keeps text layers as real, editable TextLabel instances instead of flattening them into images. A word that Figma wraps over several lines without spaces turns on RichText automatically so it looks the same in Roblox.

Text Auto Scale

Basics

Turns on Roblox's TextScaled, so text resizes to fit its container across screen sizes.

Include Text Strokes

Basics

Keeps outlined/stroked text styling from Figma on the exported TextLabel.

Auto Text Converter

Basics

If a text layer uses a font Roblox doesn't support, this automatically rasterizes just that layer into an image instead of breaking the export.

Advanced

Advanced

Tools that take a bit more setup — naming conventions and account connection — but give you more control over the result.

Tags system

Advanced

Open the Tags tab, select a layer in Figma, and click a tag to add it to the layer's name (click again to remove). Tags tell Fireporter exactly which Roblox instance type to build, overriding the automatic guess.

My Assets

Advanced

The Assets tab lets you upload your own images or whole folders, organize them, and apply one directly onto a selected Frame or Rectangle in Figma without leaving the plugin. Assets are stored only on your device.

Connect your Roblox account

Advanced

Required for Upload mode and for image uploads in Auto Mode. Open the Account tab and log in with Roblox. After you approve access in your browser, the page shows a connection code. Copy it, switch back to Figma, paste it into the Connect Roblox prompt and confirm. The code is stored only on your device, and the access it grants is limited to uploading images, as described in the privacy policy.

Support tickets

Advanced

Found a bug or need help? Open the Support tab and click Create a Support Ticket. Pick a category, describe the issue, attach a screenshot, video, or Figma/Roblox file if it helps, and leave your email so the developer can reply directly.

Beta features

Beta

The second row of toggles in the Export tab. These work, but are newer and may change — expect occasional rough edges.

Naming Intelligence

Beta

Generates cleaner instance names from tags or text content instead of raw Figma layer names, and automatically de-duplicates identical sibling names.

Respect Shadows

Beta

Exports Figma drop shadows as a Roblox UIShadow, carrying over blur radius, offset, spread, color, and transparency. Shadows on real text use the UIShadow Text mode; everything else uses Shape.

Respect Corners

Beta

Exports individually rounded corners as a Roblox UICorner, instead of forcing one uniform radius on all four corners.

Design Polish Enhancer

Beta

A cleanup pass before export: rounds positions/sizes to whole pixels, snaps spacing to an 8px grid, rounds corner radii to common steps, and aligns sibling edges and text baselines.

Auto Mode

Beta

A more hands-off export: structural layers default to Frame and text defaults to TextLabel without tagging. Figma vector path layers are exported as images (ImageLabel, or ImageButton when tagged _button), and identical images are merged so each one is uploaded only once. Text with an unsupported font is turned into an image with its shadow baked in, so it never gets a second UIShadow. If you're logged in, images are uploaded to Roblox with their asset IDs filled into the export. Without a login you still get the JSON, but images are not uploaded.

Filter (Upload mode only)

Beta

Right-click the Filter toggle to choose grayscale or a custom tint color, and which element types it applies to (text, frames, image labels, image buttons). Only affects Upload mode exports.

Preview Roblox UI

Beta

Opens a window that shows how your selection will look in Roblox Studio. See the section below for details.

Upload mode

Beta

Requires a connected Roblox account. Uploads the images in your selection to your Roblox account and writes their asset IDs into the exported JSON, so images appear as soon as you paste it into Studio. Only the images are sent for upload. The rest of your design data stays in the plugin, and you still copy the JSON and paste it into Studio yourself.

Looking for Live Mode? It has been replaced by Upload mode. Exports are no longer sent to Studio automatically. You copy the JSON and paste it, and your images are still uploaded for you.
You may also notice a locked, disabled button in the toolbar — Coming soon — that's a feature slot that isn't available yet.

Preview Roblox UI

Beta

Check your design before it ever reaches Studio. The preview is built from the same data the export produces, so strokes, corners, gradients, shadows, and text appear the way they will in Roblox.

Turn it on

Basics

Select a layer, switch on Preview Roblox UI, and the preview window opens. Use Refresh after you change something in Figma.

Matches your export mode

Basics

The preview follows Normal, Upload, ZIP, and Auto mode, so shapes that become images in Upload or Auto mode are shown as images too.

Screen size and background

Basics

Pick a screen size and a background: Dark, Light, Baseplate, or Checker. A blur slider softens the background, and you drag it with the mouse held down.

Zoom and pan

Basics

Scroll or use the zoom controls to zoom smoothly, and drag the preview to move around.

Roblox Studio plugin

Once your UI is imported, the Studio-side widget also has some controls of its own.

Position pad

Basics

Select any GuiObject in the Explorer (or use the instance you just imported) and click one of the 9 grid cells to instantly snap it to that screen anchor — top-left, center, bottom-right, and so on — using AnchorPoint and scale Position.

Target tracking

Basics

The widget shows which instance the position controls currently target, updating automatically as your Explorer selection changes or right after an import.
