Basics

Install both plugins

You need both sides for a full workflow:

  • Figma — Fireporter on Figma Community
  • Roblox Studio — Fireporter on the Creator Store

In Studio, open the plugin panel and leave a ScreenGui selected when you import (Live Mode places UI under the selected ScreenGui).

Basics

Your first export (copy & paste)

This path works offline — no Roblox login required.

  1. 01
    Select layers in Figma Pick a frame or group that represents your UI. You can select multiple top-level items.
  2. 02
    Open Fireporter in Figma Run the plugin. On the Export tab, leave Live Mode off for a normal export.
  3. 03
    Export Use the export action. Fireporter builds JSON from your selection and shows it in the code panel.
  4. 04
    Copy the output Copy the generated code from the plugin window.
  5. 05
    Paste in Studio Open the Fireporter Studio plugin, select a ScreenGui, paste the JSON, and import.
Tip: Turn on Auto Scale so sizes and positions use scale values that adapt better across devices.
Basics

Live Mode

Live Mode sends the export to your signed-in Roblox account and the Studio plugin pulls it in automatically — no copy/paste. Images can be uploaded to Roblox for you.

  1. 01
    Connect Roblox In the Figma plugin, open Account (or the login prompt) and log in with Roblox. You can also use Connect Roblox account on this site.
  2. 02
    Open Studio Fireporter Enable the dock widget and select a ScreenGui. Live polling runs while the panel is open.
  3. 03
    Enable Live Mode in Figma Turn on the Live Mode toggle, select your UI, and export.
  4. 04
    Wait for import Studio should receive the tree within a few seconds and build the instances under your ScreenGui.
Note: Image uploads follow Roblox moderation. If an image is rejected, Fireporter may show an error and a temporary lockout may apply.
Intermediate

Tags

Put tags at the end of the layer name in Figma (for example PlayButton_button). The Tags tab in the plugin lists them and can apply tags to the selection.

Tag Result in Roblox
_scroll ScrollingFrame (canvas sized from overflowing children)
_button ImageButton
_box TextBox
_frame Frame (with fill, stroke, corners, etc.)
_lock UIAspectRatioConstraint
_ignore Skipped on export
_text TextLabel
_gradient UIGradient from fills
_canvas CanvasGroup
_grayscale Grayscale filter on that object’s export
Intermediate

Export toggles

On the Export tab, toggles control what gets included:

Common (Basics+)

  • Include Strokes — export strokes as UIStroke where supported
  • Include Effects — effects such as shadows when enabled
  • Auto Scale — convert layout to scale-friendly values
  • Include Gradients — UIGradient from linear fills
  • Global Text / Text Auto Scale / Text Stroke — text handling options
  • Auto Text Converter — custom fonts become image labels when Roblox can’t use the font

BETA / optional

  • Naming Intelligence — smarter instance names
  • Respect Shadows / Corners — extra fidelity for shadows and corner radii
  • Design Polish Enhancer — experimental polish pass
Advanced

Auto Mode

Auto Mode (second-row toggle) reduces how often you need tags:

  • Frames become Frames without needing _frame
  • Text becomes TextLabels without needing _text
  • Images become ImageLabels and can upload/replace assets like Live Mode when the database allows
  • You still tag _button, _box, and _scroll when you need those types
  • Unknown types fall back to Frame
Note: Auto Mode still respects explicit tags. Prefer tags when you need a specific class.
Advanced Beta · Live

Filter

The Filter toggle (Live-oriented) applies a color filter when exporting images for Live Mode — for example grayscale. Right-click the control to open filter options (include text / frames / image labels / buttons, and color choice).

Filtering changes exported PNG pixels in Figma during export; it is not the same as setting ImageColor3 in Studio.

Advanced

My Assets

The Assets tab stores images on this device only (Figma clientStorage). Upload files or folders, then select a rectangle/frame in Figma and click an asset to apply it.

  • Prefer PNG for transparency
  • Very large files may be compressed or skipped if storage is full
  • Assets are not synced across computers

Tips & troubleshooting

  • Nothing imports in Live Mode — select a ScreenGui in Studio and keep the Fireporter widget open.
  • Images blank — Live/Auto upload may have failed; check the plugin notification and Roblox moderation state.
  • Wrong instance type — add the correct tag at the end of the name, or use Auto Mode for defaults.
  • Scrolling content — name the container with _scroll; children that overflow set canvas size.
  • Export errors — review the error list (critical / medium / small) and fix named layers, or continue if safe.
  • Support — optional tips via Ko-fi are in the plugin Support tab; community links are under Socials.
